# 教师管理插件（astrbot_plugin_teacher_manager）

让Astrbot作为教学辅助智能体的插件：让教师通过自然语言完成通知/任务分发、学生回复收集、聊天总结、学情档案管理。

## 功能总览

| 模块 | 能力 |
|---|---|
| 📣 分发与任务收集 | 管理员对话式指令 → **二次确认** → 主动推送到群/个人；含任务关键字的推送自动开启回复收集（支持截止时间+处理方式声明），到期或手动「收」后按声明方式（原文/打包/总结/评分）汇总转发给教师 |
| 📊 聊天总结 | 总结某群/某人的聊天内容 → **征求目标方同意**（群需群主/管理员，私聊需本人）→ LLM 压缩提炼发教师，可选附原文文档；支持**定时规则**（每天/每周某天定时自动总结） |
| 👤 用户档案 | 每个用户本地 markdown 档案：自动收录对话摘录、LLM 定期总结学情特征（常问知识点/薄弱点/进步情况）；管理员可查/增/删，可提问「某同学最近薄弱点在哪」 |
| 📜 EULA 门禁 | 可开关。开启后新用户首次使用（群聊需 @bot）收到使用条款，回复「同意」解锁；未同意者只收到预设提示，不触达 LLM |

## 安装

1. 将本插件放入 AstrBot 的插件目录下
2. WebUI 中启用该插件

## 使用指南
### 📣 推送与任务

```
把明天带实验报告通知推送给三班
请大家今晚交作业 发到 三班
通知三班明天早上八点集合
把讲义发到 <群号>
```

插件复述内容与目标 → 回复 **「确认」**（或「取消」）→ 发送，支持多目标。
- 内容含「任务/作业/提交/收集/截止/回复」等词 → 自动开启**回复收集**
- 学生回复后，对 bot 说 **「收」** 立即结束并汇总
- 支持截止时间：`... 截止明天18点` → 到点自动收卷
- 声明处理方式：`... 收集完打包` / `... 收集完做总结` / `... 收集完评分，按完成度和正确性打分`

### 📊 聊天总结

```
总结三班最近两天的聊天
总结小明最近一周的对话
```

- 目标方收到申请 → 回复「同意」后自动总结发给教师
- 群聊同意需**群主/管理员**回复，私聊需**对象本人**回复
- 定时规则：
  ```
  每天21:30总结三班
  每周日晚8点总结三班
  /规则          → 查看当前规则
  /规则 del r_xxx → 删除规则
  ```
- 同意可设置为一定期限内有效，期内定时总结免二次确认
- `agreement_valid_days` 填 0 表示永久有效，变更配置时自动重置全部同意记录

### 👤 用户档案

```
小明最近有什么薄弱点？
分析一下小美的成绩进步情况
/档案 10001             → 查看完整档案
/档案 小明 add 上次月考92分，数列薄弱
/档案 10001 del 三角函数
```

- 每个对话用户自动建立档案
- 对话摘录满一定数量可自动触发 LLM 特征总结
- 管理员可手写补充或删除条目

### 📜 EULA

- 配置 `eula_enabled` 开启后，新用户（群聊需 @bot）收到 可自定义的EULA，回复「同意」解锁
- 未同意者只收到 `eula_deny_tip` 预设提示，不触达 LLM

### 指令

| 指令 | 说明 |
|---|---|
| `/推送 <内容> <对象>` | 推送并自动识别任务语义 |
| `/总结 <对象> [最近 X 天]` | 总结聊天 |
| `/档案 <QQ或称呼> [show\|add <内容>\|del <关键词>]` | 档案管理 |
| `/规则 [del <规则id>]` | 查看/删除定时规则 |
| `/收 [任务id]` | 结束任务收集并汇总 |
| `/同意` | 管理员手动确认总结申请 |
| `/取消` | 取消待确认操作 |
| `/任务` | 查看进行中的任务/规则/待确认操作概览 |
